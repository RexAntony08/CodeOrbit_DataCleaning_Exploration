## Task 1 Summary
Loaded a raw sales dataset, handled missing values, removed duplicates, fixed incorrect data types, and
generated basic statistics (mean, median, value counts). See task1_cleaning_report.md for full details.

## Task 2 Summary
Performed EDA on the cleaned dataset using pandas, matplotlib, and seaborn. Created histograms, bar charts,
and scatter plots to identify patterns and trends in customer age, product revenue, and price. See
task2_eda_report.md for full details.

## Task 3 Summary
Built and evaluated a linear regression model using scikit-learn to predict revenue from price, achieving
an R² of 0.999 on the full dataset. Visualized the regression line against actual data points. See
task3_regression_report.md for full details.
